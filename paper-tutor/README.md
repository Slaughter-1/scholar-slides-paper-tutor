# Paper-Tutor

Paper-Tutor is the teaching layer for source-grounded academic paper work. In Integrated Mode it consumes a matching Scholar-Slides reading view and evidence set; in Standalone Mode it clearly reports that Scholar-Slides CKPT-1 verification was unavailable.

Use the bundled references for integration and evidence, teaching depth, full-paper output contracts, benchmark papers, reading completion, validation scenarios, and Learning Map synchronization. Keep Scholar-Slides upstream read-only. Separate Paper Facts, Tutor Explanation, and Tutor Analysis, preserve unresolved evidence, and never promote an unsupported claim.

For complete-paper delivery, emit the required status line, claim-to-evidence appendix, formula/figure/table contracts, and `READING COMPLETE` only when the reading-completion gate is satisfied. Otherwise report `READING INCOMPLETE` with the missing items.
